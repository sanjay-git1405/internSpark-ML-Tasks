# internSpark Machine Learning Internship Tasks

## Objective
This repository contains the completed tasks for the internSpark Machine Learning internship. The objective is to demonstrate hands-on experience with classic machine learning workflows, including exploratory data analysis, data preprocessing, feature engineering, model training, and evaluation.

## Completed Tasks
1. **Task 1: Iris Classification** - Exploratory data analysis and a baseline Logistic Regression model to classify iris species.
2. **Task 2: House Price Prediction** - Regression analysis and a baseline Linear Regression model to predict California housing prices.
3. **Task 3: Titanic Survival Prediction** - Handling missing data, feature engineering, and a Logistic Regression model to predict passenger survival.

## Requirements
To completely reproduce these results, ensure you have the following packages installed in your Python environment:
* Python 3.x
* pandas
* numpy
* scikit-learn
* matplotlib
* seaborn
* jupyter

## Instructions to Run
Follow these exact commands to reproduce the results locally:

1. Clone this repository:
   git clone https://github.com/[your-username]/internSpark-ML-Tasks.git

2. Navigate into the project directory:
   cd internSpark-ML-Tasks

3. Install the required dependencies:
   pip install pandas numpy scikit-learn matplotlib seaborn jupyter

4. Open the notebooks:
   If using VS Code, simply open the `.ipynb` files. Alternatively, run `jupyter notebook` in your terminal and open the files via your browser.

5. Execute the code:
   Run all cells sequentially in `Task_1_Iris_Classification.ipynb`, `Task_2_House_Price_Prediction.ipynb`, and `Task_3_Titanic_Survival.ipynb`.
